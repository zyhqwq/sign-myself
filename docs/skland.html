森空岛 Token 获取

两种方式任选：App 扫码，或书签栏一键读取。全程在你的浏览器内完成

方式一：森空岛 App 扫码推荐

  1. 打开森空岛 App，点右上角「扫一扫」
  2. 扫描下方二维码，在手机上点击「确认登录」
  3. Token 会自动生成在页面底部，复制即可

代理设置（首次使用需配置一次）

扫码需要一个小型 CORS 代理转发鹰角接口（官方接口仅允许自家域名跨域）。请按 README 部署你自己的 Cloudflare Worker（docs/proxy.js），然后把地址填到这里。Token 只在你的浏览器内组装，代理无日志无存储。与米游社扫码页共用同一代理地址。

你的 Token（已累计 0 个账号）
多账号 Token 已自动用英文逗号连接，整段复制填入 Secret / api.txt 的 SKLAND_TOKEN 即可。

方式二：书签栏一键获取无需扫码

  1. 登录森空岛网页版（www.skland.com）或鹰角网络通行证
  2. 把下方按钮按住拖到浏览器书签栏松开
    （书签栏没显示？按 Ctrl+Shift+B / Mac ⌘+Shift+B 打开）
  3. 回到森空岛标签页，点击书签栏里的「📋 获取森空岛Token」，Token 会自动弹出并复制

拖不动？手动添加书签

在书签栏右键 →「添加网页」/「新建书签」，名称随意（如 获取Token），地址粘贴下面这段；或在下面点「复制链接」，再粘到书签地址里。

不用书签？传统手动方法

1. 在电脑浏览器登录 森空岛；
2. 打开 web-api.skland.com/account/info/hg；
3. 复制返回 JSON 中 {"content":"****"} 里 **** 的内容即为 Token。

常见问题

⚠️ Token 等同账号密码，仅填入 GitHub Secrets 或 api.txt，切勿告知他人或公开发布。

· 扫码提示「代理请求失败 / 未配置代理」：按上方「代理设置」说明部署并填入你的 Worker 地址。
· 点击书签后提示「请求失败 / 未获取到」：说明该标签页未登录，请先登录森空岛网页版。
· 多账号：扫码可连续添加；书签方式用浏览器无痕窗口分别登录各取一次。多账号 Token 用英文逗号 , 连接填入。
· 获取后请不要在网页或 App 上点击「退出登录」（会使 Token 失效）。
