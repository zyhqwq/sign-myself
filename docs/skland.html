森空岛 Token 一键获取

把按钮拖到书签栏，在已登录的森空岛页面点一下，Token 自动复制。全程在你的浏览器内完成
  1. 登录森空岛网页版（www.skland.com）或鹰角网络通行证
  2. 把下方按钮按住拖到浏览器书签栏松开
    （书签栏没显示？按 Ctrl+Shift+B / Mac ⌘+Shift+B 打开）
  3. 回到森空岛标签页，点击书签栏里的「📋 获取森空岛Token」，Token 会自动弹出并复制

拖不动？手动添加书签

在书签栏右键 →「添加网页」/「新建书签」，名称随意（如 获取Token），地址粘贴下面这段；或在下面点「复制链接」，再粘到书签地址里。

不用书签？传统手动方法

1. 在电脑浏览器登录 森空岛；
2. 打开 web-api.skland.com/account/info/hg；
3. 复制返回 JSON 中 {"content":"****"} 里 **** 的内容即为 Token。

常见问题

⚠️ Token 等同账号密码，仅填入 GitHub Secrets 或 api.txt，切勿告知他人或公开发布。

· 点击书签后提示「请求失败 / 未获取到」：说明该标签页未登录，请先登录森空岛网页版。
· 多账号：用浏览器无痕窗口分别登录不同账号各取一次，多账号 Token 用英文逗号 , 连接填入。
· 获取后请不要在网页上点击「退出登录」（会使 Token 失效）；直接关掉标签页即可。
