代理设置（首次使用需配置一次）

本页需要一个小型 CORS 代理访问 B 站接口（官方接口仅允许自家域名跨域）。请按 README 部署你自己的 Cloudflare Worker（docs/proxy.js），然后把地址填到这里。Cookie 只在你的浏览器内解析，代理无日志无存储。与米游社/森空岛扫码页共用同一代理地址。

你的 Cookie（已累计 0 个账号） Secret：BILI_SESSDATA（必需） Secret：BILI_DEDEUSERID（必需） Secret：BILI_JCT（可选，建议填写）
多账号各字段已自动用英文逗号连接，按位置一一对应；逐个复制填入同名 Secret 即可。

⚠️ Cookie 等同账号密码，仅填入 GitHub Secrets 或 api.txt，切勿告知他人或公开发布。

· 提示代理相关错误时，请在上方「代理设置」检查 Worker 地址。
· 二维码约三分钟有效，过期后点「重新生成二维码」。
· `SESSDATA` 过期后（通知提示 Cookie 已失效）重新扫码即可。
